## Load-bearing questions

## Key findings

### Format schism resolved
The swarm surfaced a **High-severity contradiction**: code/text agents recommended JSONL while visual/multi-modal agents recommended WebDataset/Parquet. Resolution: **JSONL for code/text, WebDataset/Parquet for visual/multi-modal at scale, with a translation layer** between them. This is now canon.

### Metadata backbone: Croissant
Agents 1 (code) and 2 (visual) both converged on structured metadata. The doctrine recommends **Croissant** (Google/MLCommons, 2023) as the backbone schema, with modality-specific extensions drawn from The Stack (code) and LAION (visual) field conventions.

### Quality gates
Five non-negotiable gates before any dataset ships:
1. **Contamination check** — 13-gram + embedding similarity + AST dedup for code; pHash + CLIP score for visual
2. **License scan** — SPDX identifier required; conflict detection via `license-expression` parsing
3. **Evidence requirement** — Every dataset must have ≥1 pressure-test or dogfood run
4. **Diversity floor** — Entropy check to prevent synthetic collapse (Shumailov et al., 2023)
5. **Toxicity/PII audit** — Detoxify + AEGIS classifiers for text; [INFERRED] visual PII tools not yet specified
