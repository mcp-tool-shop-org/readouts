# cargo-modules: Cargo, crates, modules & editions (wave 1, essentials)

**Q1. What decides the bytes?** Cargo.toml (crate-type, edition, the root `[profile]`, requirements and features), Cargo.lock (exact versions), rust-toolchain.toml (the compiler, but only when cargo runs in its directory) and `.cargo/config.toml` (rustflags and profile overrides). `RUSTFLAGS`, `CARGO_ENCODED_RUSTFLAGS` and `CARGO_PROFILE_*` outrank those files.

**Q2. How do features, editions and profiles interact across the graph?** Features unify: each dependency is built with the union of requested features. Editions stay per crate, and the solver's graph holds all four. Profiles are global: only the root's apply, to every crate.

1. **Any `RUSTFLAGS`, even empty, silently replaces config rustflags; `CARGO_ENCODED_RUSTFLAGS` outranks it; `RUSTFLAGS` splits on whitespace.** Rust project 2026 (The Cargo Book: Configuration, https://doc.rust-lang.org/cargo/reference/config.html). Measured on a solver copy: a remap-only `RUSTFLAGS` left zero `relaxed-simd` in the log. Implication: keep build.mjs's repeated pin, or pass the flags as `CARGO_ENCODED_RUSTFLAGS` (measured: same build, nothing recompiled).
2. **On 1.98.1 the `-relaxed-simd` pin leaves the real solver's bytes unchanged; `+relaxed-simd` changes them.** Rust project 2026 (rustc Book: wasm32-unknown-unknown, https://doc.rust-lang.org/rustc/platform-support/wasm32-unknown-unknown.html): default features follow LLVM and changed in 1.87. Implication: the pin guards against a default flip. Never drop it.
3. **Both the toolchain file and the config are found from the cwd.** Rust project 2026 (rustup book: Overrides, https://rust-lang.github.io/rustup/overrides.html). Measured: `--manifest-path` from the parent ran the stable rustc and applied no config rustflags. Implication: build only through build.mjs (`cwd: solver`).
4. **`"0.35.3"` means >=0.35.3, <0.36, and only `--locked` stops a silent lock rewrite.** Rust project 2026 (Cargo Book: cargo build, https://doc.rust-lang.org/cargo/commands/cargo-build.html). Implication: add `--locked` to build.mjs's cargo arguments.
5. **A feature enabled anywhere in a build is on for every user of that crate.** Rust project 2026 (Cargo Book: Features, https://doc.rust-lang.org/cargo/reference/features.html). Measured: rapier3d-f64 gets alloc, block-solver, default, dim3, enhanced-determinism, f64, std, and never parallel. Implication: guard with `cargo tree -e features -i rapier3d-f64`.
6. **Only the root's `[profile]` counts, and config files and env vars override it.** Rust project 2026 (Cargo Book: Profiles, https://doc.rust-lang.org/cargo/reference/profiles.html). Rust project 2024 (Announcing Rust 1.77.0, https://blog.rust-lang.org/2024/03/21/Rust-1.77.0/): the strip default. Measured: the solver's profile differs from default release only in panic and codegen-units, and Cargo adds `-C strip=debuginfo` unasked. Implication: consider pinning `strip` and `debug`.
7. **A root workspace moves the lock and target/, ignores member profiles, and stops reading member configs.** Rust project 2026 (Cargo Book: Workspaces, https://doc.rust-lang.org/cargo/reference/workspaces.html). Implication: plan the host-binding workspace so the profile and the relaxed-SIMD pin move to the root.
8. **`crate-type = ["cdylib", "rlib"]` changes the wasm digest.** Rust project 2026 (Reference: Linkage, https://doc.rust-lang.org/reference/linkage.html). Measured: 1,524,412 → 1,524,440 bytes. A cdylib-only crate still runs in-crate unit tests. Implication: test the private helpers in `#[cfg(test)]` modules, not `tests/`.
9. **`cargo fix --edition` never edits the edition key.** Rust project 2026 (Cargo Book: cargo fix, https://doc.rust-lang.org/cargo/commands/cargo-fix.html). Measured: 3 fixes (`#[unsafe(no_mangle)]`, `unsafe extern`), and the `static mut` reference was left for hand work. Implication: the solver can stay on 2021. `#[unsafe(no_mangle)]` compiles in 2021 already.
10. **Edition 2024 implies MSRV-aware resolver 3, and a virtual workspace without `resolver` falls back to 1.** Rust project 2025 (Announcing Rust 1.84.0, https://blog.rust-lang.org/2025/01/09/Rust-1.84.0/). Implication: set `resolver` explicitly in any root workspace.

**Thin evidence.** Every byte comparison is a Windows build with scratch paths: relative, same host, not the pinned Linux digest. Cross-host behaviour was not tested. Why `rlib` moves the digest is unexplained. The `strip`/`debug` pins are a suggestion, not measured.
