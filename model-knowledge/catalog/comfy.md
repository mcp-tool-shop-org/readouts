## Detail

### ComfyUI · `recommended` · frontier
The node-graph engine you build everything else on. RE-DOWNLOAD PATH FOR THIS RIG (RTX 5090, Blackwell sm_120): the early-2026 'install PyTorch nightly cu128 by hand' headache is OVER as of mid-2026. PyTorch 2.7.0 was the first STABLE release with native sm_120 / CUDA 12.8 wheels, and the OFFICIAL ComfyUI Windows portable now ships CUDA 13.0 + Python 3.13 baked in -- so a 5090 runs on a clean install with zero nightly gymnastics. Two supported front doors: (1) Portable .7z (power-user default, latest features, everything self-contained) -- download ComfyUI_windows_portable_nvidia.7z from the GitHub releases 'latest' link, extract with 7-Zip, run run_nvidia_gpu.bat. Do NOT use the cu126 package (that's for 10-series/older). (2) Desktop installer (NSIS, auto-manages the Python env, one-click migrate, good for a clean reformat) -- still labelled Beta. Manual git clone is the third option for devs. After install, immediately add ComfyUI-Manager (see extras) to handle every other node. Pitfall that still bites on Blackwell: never `pip install xformers` into the embedded Python -- it drags in a stale torch and clobbers the working CUDA build; the modern accel stack is SageAttention + triton-windows + torch.compile (KJNodes exposes these). VRAM: ComfyUI itself is thin; the 32 GB card is what lets you run Flux/Wan/Hunyuan3D at full precision -- see the model-lane agents for those weights.
- **Dev:** Comfy Org (comfyanonymous + Comfy-Org) · **Arch:** PyTorch node-graph runtime · **Params:** n/a (application / inference engine) · **Released:** ongoing (rolling releases; portable refreshed continuously) · **VRAM:** min 4.0 GB / rec 8.0 GB

Crucial caveat for game-asset work: the SOFTWARE license says nothing about the MODELS -- each checkpoint/LoRA you load carries its OWN license (e.g. FLUX.1-dev is NON-commercial; FLUX.1-schnell and SDXL are commercial-safe). Commercial safety is decided per-model, not by ComfyUI.
- **Best for:** Backbone for all local image/video/3D generation on this rig -- concept art, sprites, textures, 3D base meshes (both, fit 5) ; Repeatable, parameterized asset pipelines (batch sprite sheets, texture variants, LoRA-driven style locks) (game-asset, fit 5) ; Marketing/social image + short-video generation with full control over composition (marketing, fit 5)
- **Speed/notes:** On a 5090 with the stock CUDA-13 portable, SDXL is effectively real-time and Flux-class models are comfortable; SageAttention + torch.compile give a further large speedup on attention-heavy diffusion/video models.
