### LTX-2.3 (LTX-2 family, 19B) · `recommended` · frontier
The speed-and-fidelity champion for a 32 GB rig and the only mainstream open model with NATIVE synchronized AUDIO+video — huge for marketing deliverables where you want sound without a second tool. On an RTX 5090 it was ~5.7x faster than Wan 2.2 14B at equivalent I2V settings, and the distilled (8-step) variants push that further. Supports T2V and I2V up to 4K native and up to ~60s, 24-50 fps. Built into ComfyUI core (needs ComfyUI >= v0.16; reference T2V/I2V/multi-stage-upscale workflows ship with it). The catch is licensing (see commercial notes): not pure Apache 2.0. Use the fp8/fp4 19B or the distilled model on 32 GB; the full bf16 19B is heavy. Comfy maturity: native, well-supported, with the dedicated Lightricks/ComfyUI-LTXVideo node pack for the latest pipelines.
